# 🐝 HiveFive — Educational Word Guessing Game

A fun and colorful mobile game designed to help players learn vocabulary
through word guessing across different categories.

---

## 🎮 Gameplay

Choose a category and guess the hidden word by identifying the correct letters.
Each round gives you a clue through images — figure out the word before you run out of chances!

---

## ✨ Features

- 📚 **Multiple categories** — Animals, Fruits, Numbers, and Colors
- 🖼️ **Image-based clues** — Visual hints to guide your guess
- ✅ **Feedback system** — Good Job and Perfect ratings based on performance
- ⏸️ **Pause anytime** — Quit or resume mid-game
- 🌟 **Results screen** — See how well you did after each round

---

## 🛠️ Built With

Java, Android Studio
